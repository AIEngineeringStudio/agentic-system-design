The flat version will use filename-based routing, with no folder paths required
inside ChatGPT Projects.

One important distinction: ChatGPT Projects treat uploaded files as reference
material. The routing rules must be pasted into Project settings → Project
instructions; uploading `SKILL.md` alone does not activate it as an installed
skill.

## Flat AI Study Tutor

chatgpt-project-flat.zip

- 23 files
- 73 design problems
- 9 modules
- 8 dedicated anchor references
- 2 concept references

### Key files

| File                     | Purpose                                            |
|--------------------------|----------------------------------------------------|
| PROJECT_INSTRUCTIONS.txt | Ready to paste into Project Instructions           |
| SKILL.md                 | Progressive teaching behavior and filename routing |
| sdt-catalog.md           | Case-to-module mapping                             |
| README.md                | Setup and usage instructions                       |

All 16 recommended anchor cases remain in the catalog.
Eight have dedicated deep-dive files; the others use their module references.

### Installation

1. Extract the `chatgpt-project-flat` ZIP.
2. Paste `PROJECT_INSTRUCTIONS.txt` into your ChatGPT Project Instructions.
3. Upload `SKILL.md`, `sdt-catalog.md`, and relevant Markdown files as Project
   Sources.
4. **Test with:** “Teach AI system design #36, starting with requirements.”
