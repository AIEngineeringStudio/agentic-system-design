# Native Agent Skills vs CHATGPT Projects

## Native Agent Skills

- It supports automatic skill activation
- It supports structured references.

## CHATGPT Projects

In **ChatGPT Projects**:

- It supports instruction-based routing.
- Project Sources use uploaded files and Project Instructions.

> Note: It does not guarantee that only the specified source files enter the
> model's context. If the tutor cannot retrieve a reference, it should identify
> the missing filename rather than pretend it loaded it.
